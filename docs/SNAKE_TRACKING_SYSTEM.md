# 🐍 草蛇灰线系统

## 系统概述

草蛇灰线系统是一个自动化的特级事件追踪系统，能够：

1. **自动识别特级事件** - 从新闻流中识别需要深度追踪的重大事件
2. **历史脉络分析** - 回溯事件发展历程，构建完整时间线
3. **持续进展监控** - 实时监控事件新进展，自动更新分析
4. **智能终止判断** - 自动判断事件是否已结束，生成最终报告

## 核心功能

### 1. 事件晋升与捕猎

当系统发现特级事件或新闻持续发酵时，会自动：
- 将事件晋升为"捕猎对象"
- 回溯过去7天的相关新闻
- 生成事件发展脉络
- 创建初始追杀令报告

**晋升标准：**
- 🔥 **特级事件**：军事冲突、重大灾害、金融波动(>5%)、政治变动等
- 📈 **持续发酵**：24小时内3条以上相关新闻，多地区连锁反应
- ⚠️ **系统风险**：可能引发连锁反应，影响区域稳定的事件

### 2. 持续监控与进展更新

系统每分钟检查新闻流，发现捕猎对象的新进展时：
- 自动生成进展更新报告
- 实时推送重要进展通知
- 更新事件时间线和影响分析

### 3. 智能终止与蛰伏

当事件满足终止条件时，系统会：
- 生成最终报告
- 分析事件的整体影响
- 将捕猎对象转为蛰伏状态

**终止条件：**
- 超过7天无重要进展
- 事件有明确结论（协议达成、危机解决等）
- 影响已衰减，转为常态

## 系统架构

```
草蛇灰线系统
├── 事件捕猎服务 (huntService.js)
│   ├── AI事件识别
│   ├── 历史脉络构建
│   └── 追杀令生成
├── 持续跟踪服务 (trackingService.js)
│   ├── 进展监控
│   ├── 进展更新生成
│   └── 终止条件判断
└── 主服务 (snakeTrackingService.js)
    ├── 系统协调
    ├── 状态管理
    └── 通知推送
```

## 使用方法

### 自动运行

系统集成在主服务中，会自动运行：

```bash
npm start  # 启动完整系统，包含草蛇灰线
```

### 手动操作

#### 查看系统状态
```bash
npm run snake:status
```

#### 手动触发事件捕猎检查
```bash
npm run snake:hunt
```

#### 手动触发进展检查
```bash
npm run snake:progress
```

#### 生成系统报告
```bash
npm run snake:report
```

#### 健康检查
```bash
npm run snake:health
```

#### 手动终止捕猎对象
```bash
# 先查看活跃的捕猎对象ID
npm run snake:status

# 终止指定对象
node src/scripts/snakeTrackingTrigger.js terminate hunt_1234567890_abc123
```

## 调度配置

系统按以下频率自动运行：

| 任务 | 频率 | 说明 |
|------|------|------|
| 进展监控 | 每分钟 | 检查活跃捕猎对象的新进展 |
| 事件捕猎 | 每5分钟 | 在新闻流中寻找特级事件 |
| 终止检查 | 每小时 | 检查是否有捕猎对象需要终止 |

- 新闻数据：`data/news/YYYY/MM/DD/news_*.json`

## 通知机制

系统会通过Webhook发送以下通知：

1. **🎯 新捕猎目标** - 发现特级事件时
2. **🔄 最新进展** - 捕猎对象有新进展时  
3. **🏁 追踪结束** - 捕猎对象终止时
4. **⚠️ 系统异常** - 出现错误时

## 监控指标

### 关键指标

- 活跃捕猎对象数量
- 每日新增捕猎对象数
- 平均追踪时长
- 进展更新频率
- 自动终止比例

### 健康检查

```bash
npm run snake:health
```

检查项：
- ✅ 系统初始化状态
- ✅ 各服务组件状态
- ✅ 活跃捕猎对象数量
- ✅ 最近检查时间

## 配置参数

可在 `snakeTrackingService.js` 中调整：

```javascript
this.huntCheckInterval = 5;        // 事件捕猎检查间隔（分钟）
this.progressCheckInterval = 1;    // 进展检查间隔（分钟）
this.terminationCheckInterval = 60; // 终止检查间隔（分钟）
```

回溯时间窗口：
```javascript
const sevenDaysAgo = moment().subtract(7, 'days'); // 可调整回溯天数
```

## 故障排除

### 常见问题

1. **系统未初始化**
   ```bash
   npm run snake:init
   ```

2. **捕猎对象无法终止**
   - 检查ID是否正确
   - 确认对象状态为active

3. **AI分析失败**
   - 检查LLM服务配置
   - 查看日志了解具体错误

## 扩展性

### 自定义晋升规则

修改 `webhookService.js` 或各服务中的通知方法，自定义消息格式。
