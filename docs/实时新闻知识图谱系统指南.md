# 实时新闻知识图谱系统 (Real-time News Knowledge Graph)

## 🌟 系统概述

实时新闻知识图谱系统是一个基于Node.js + Neo4j的高性能新闻处理平台，实现从原始新闻摄入到智能分析存储的全流程自动化处理。系统采用微服务架构，支持实时爆点检测、智能实体归一化、事件合并等先进功能。

### 🔄 处理流程

```
┌───── 新闻摄入 ─────┐    ┌───── LLM提取 ─────┐    ┌───── 实时警报 ─────┐    ┌───── 图谱存储 ─────┐
│   每分钟拉取30-100条   │ →  │  5W1H + 爆点检测   │ →  │   <5秒内发送警报    │ →  │  Neo4j图数据库存储   │
│   • RSS/API聚合      │    │  • AI智能提取      │    │  • 钉钉/Slack通知   │    │  • 实体归一化       │
│   • 数据验证过滤      │    │  • 事件分类标记     │    │  • 防重复机制       │    │  • 事件合并去重      │
│   • 内存队列缓存      │    │  • 情感分析        │    │  • 多渠道发送       │    │  • 关系网络构建      │
└─────────────────────┘    └───────────────────┘    └───────────────────┘    └───────────────────┘
```

## 🚀 核心特性

### 📰 智能新闻摄入
- **多源聚合**: 支持RSS、API等多种新闻来源
- **实时监控**: 每分钟自动拉取最新新闻
- **数据验证**: 自动过滤无效数据和重复内容
- **背压控制**: 智能队列管理，防止内存溢出

### 🤖 AI智能提取
- **5W1H分析**: Who、Where、When、What、How智能提取
- **事件分类**: 财经、政治、冲突、科技、社会等自动分类
- **爆点检测**: 基于关键词和语义的爆点识别
- **实体识别**: 人物、公司、地点等实体自动提取

### ⚡ 实时警报系统
- **秒级响应**: 爆点新闻5秒内触发警报
- **多渠道通知**: 支持钉钉、Slack、自定义Webhook
- **防重复机制**: 智能去重避免警报轰炸
- **可配置规则**: 支持自定义爆点检测规则

### 🗄️ 知识图谱存储
- **Neo4j图数据库**: 高性能图存储和查询
- **实体归一化**: 智能合并同一实体的不同表达
- **事件合并**: 基于指纹算法的相似事件合并
- **关系网络**: 构建实体间复杂关系网络

## 🏗️ 系统架构

### 核心模块

```
src/realtime/
├── config.js              # 系统配置中心
├── memoryQueue.js          # 高性能内存队列
├── ingestRaw.js           # 数据摄入服务
├── llmExtract.js          # LLM信息提取
├── realtimeAlert.js       # 实时警报服务
├── analysisStore.js       # 分析存储服务
├── aliasDict.js           # 实体别名字典
└── fingerprint.js         # 事件指纹系统
```

### 数据模型

#### Neo4j 图结构
```cypher
# 节点类型
(:Entity)    # 实体节点 - 人物、公司、地点等
(:Event)     # 事件节点 - 新闻事件
(:Article)   # 文章节点 - 原始新闻

# 关系类型
-[:MENTIONED_IN]->      # 实体在文章中被提及
-[:PARTICIPATED_IN]->   # 实体参与事件
-[:DESCRIBES]->         # 文章描述事件
-[:ALIAS_OF]->          # 实体别名关系
-[:RELATED_TO]->        # 相关关系
```

## 📦 安装部署

### 前置要求

- **Node.js**: v18+ 
- **Neo4j**: v5+ (推荐使用Neo4j Desktop或AuraDB)
- **内存**: 建议4GB+
- **存储**: 建议10GB+

### 安装步骤

1. **克隆项目**
```bash
git clone <repository-url>
cd drudge
```

2. **安装依赖**
```bash
npm install
```

3. **配置环境变量**
```bash
cp .env.example .env
```

编辑 `.env` 文件：
```env
# Neo4j 数据库配置
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=your_password
NEO4J_DATABASE=neo4j

# AI服务配置
DEEPSEEK_API_KEY=your_deepseek_api_key

# 警报配置 (可选)
DINGTALK_WEBHOOK_URL=your_dingtalk_webhook
SLACK_WEBHOOK_URL=your_slack_webhook
CUSTOM_WEBHOOK_URL=your_custom_webhook

# 开发模式 (可选)
NODE_ENV=development
```

4. **初始化数据库**
```bash
# 创建数据库结构和索引
npm run realtime:schema
```

## 🔧 配置说明

### 核心配置 (src/realtime/config.js)

```javascript
export const REALTIME_CONFIG = {
  // 数据获取配置
  INGEST: {
    INTERVAL_MS: 60 * 1000,    // 拉取间隔: 1分钟
    BATCH_SIZE: 50,            // 批次大小: 50条
    MAX_QUEUE_SIZE: 1000,      // 队列大小: 1000条
  },

  // LLM提取配置  
  EXTRACT: {
    BATCH_SIZE: 10,            // LLM批量处理: 10条
    POLL_INTERVAL_MS: 1000,    // 轮询间隔: 1秒
    MAX_RETRIES: 3,            // 最大重试: 3次
    TIMEOUT_MS: 30000,         // 超时时间: 30秒
  },

  // 实时警报配置
  ALERT: {
    POLL_INTERVAL_MS: 500,     // 检查间隔: 0.5秒
    DUPLICATE_CHECK_HOURS: 2,  // 去重时间窗口: 2小时
    WEBHOOK_TIMEOUT_MS: 5000,  // Webhook超时: 5秒
  },

  // 爆点检测关键词
  BREAK_KEYWORDS: {
    HIGH_PRIORITY: [
      'surge', 'blasts', 'emergency', 'resigns', 'crash',
      '暴涨', '爆炸', '紧急', '辞职', '崩盘', '危机'
    ],
    MEDIUM_PRIORITY: [
      'significant', 'major', 'important', 'critical',
      '重要', '重大', '关键', '显著'
    ]
  }
};
```

### 别名字典配置

系统内置了丰富的实体别名字典，支持：

- **人物别名**: 马斯克 ↔ 埃隆马斯克 ↔ Elon Musk
- **公司别名**: 特斯拉 ↔ Tesla ↔ TSLA
- **地点别名**: 北京 ↔ Beijing ↔ 首都
- **货币别名**: 美元 ↔ USD ↔ Dollar

可通过代码动态添加新的别名映射。

## 🔍 故障排查

### 常见问题

**1. Neo4j连接失败**
```
错误: 数据库连接失败
解决: 检查 NEO4J_URI、用户名密码是否正确
```

**2. AI服务调用失败**
```
错误: LLM调用失败
解决: 检查 DEEPSEEK_API_KEY 是否有效，或启用开发模式
```

**3. 内存使用过高**
```
错误: 队列内存使用过高
解决: 调整 MAX_QUEUE_SIZE 或增加系统内存
```

**4. 警报发送失败**
```
错误: Webhook发送失败
解决: 检查网络连接和Webhook URL是否正确
```
