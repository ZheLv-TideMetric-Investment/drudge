# 5级News Level功能说明

## 概述

将新闻分级系统从4级升级为**5级News Level**，实现更精细化的新闻分类和推送策略，以更好地反映新闻的紧急性、重要性和影响范围。

---

## 功能升级详情

### 升级前 - 4级系统
- **Level 1**: Critical News (紧急新闻)
- **Level 2**: High Priority News (高优先级新闻)  
- **Level 3**: Regular News (常规新闻)
- **Level 4**: Low Priority News (低优先级新闻)

### 升级后 - 5级系统
- **Level 1**: Critical News (紧急新闻) 🚨
- **Level 2**: High Priority News (高优先级新闻) ⚠️
- **Level 3**: Medium Priority News (中等优先级新闻) 📊
- **Level 4**: Low Priority News (低优先级新闻) 📋
- **Level 5**: Informational News (信息性新闻) 📝

---

## 详细分级标准

### Level 1 - Critical News (紧急新闻) 🚨

**定义**: 对全球金融市场、经济体系或政治环境有**极大冲击性**的新闻，通常不可预见且引起市场强烈反应。

**示例**:
- 全球经济危机 (如2008年金融危机)
- 国际冲突或战争爆发
- 全球流行病大规模爆发
- 重要政府领导人突然去世或辞职
- 国家级金融政策重大变动 (如大规模降息/货币贬值)

**影响范围**: 全球或多个国家，影响金融市场、政治稳定、全球供应链

**推送策略**: 立即推送，无条件启用

---

### Level 2 - High Priority News (高优先级新闻) ⚠️

**定义**: 具有**高度重要性**但不如Level 1紧急，通常影响重大经济体或企业决策、股市等。

**示例**:
- 央行政策调整 (美联储加息/降息)
- 国际贸易政策变动 (关税政策变化)
- 重大企业并购或破产
- 国家级财政政策改革 (税改计划)
- 股市大幅波动 (主要股指跌幅超10%)

**影响范围**: 主要影响经济体、金融市场、特定行业或大公司

**推送策略**: 重要推送，默认启用

---

### Level 3 - Medium Priority News (中等优先级新闻) 📊

**定义**: 对某些行业、公司或地区具有较高重要性，但对全球或宏观经济影响较小。

**示例**:
- 行业重要事件 (新能源汽车销售量暴增)
- 重要公司财报发布 (苹果发布最新财报)
- 经济数据发布 (就业数据、通胀数据公布)
- 政治选举结果 (地方政府选举)
- 重大公司高层变动 (CEO辞职或任命)

**影响范围**: 对行业或特定公司有较大影响，可能引起短期市场波动

**推送策略**: 可选推送，默认关闭

---

### Level 4 - Low Priority News (低优先级新闻) 📋

**定义**: 对市场、行业或公司产生较小影响，更多是背景性信息或单一事件。

**示例**:
- 公司新产品发布 (但影响力有限)
- 市场分析报告 (投资银行发布市场趋势分析)
- 地方性政治变化 (地方政府通过一项经济政策)
- 公司内部变动 (某公司新聘高管)
- 小型行业会议或研讨会

**影响范围**: 通常是局部影响，对宏观经济或全球市场几乎无影响

**推送策略**: 订阅推送，默认关闭

---

### Level 5 - Informational News (信息性新闻) 📝

**定义**: 对当前事件的**补充性说明**或没有直接市场影响，主要用于增加对特定话题的了解。

**示例**:
- 新闻更新 (某公司扩展至新市场)
- 行业内日常运营新闻 (某公司完成季度报告发布)
- 消费者数据 (某产品销量回升)
- 宏观经济报告细节更新 (某个国家的货币供应量更新)
- 会议纪要、背景介绍等

**影响范围**: 仅提供信息更新，一般不会对市场或投资者产生直接影响

**推送策略**: 背景推送，默认关闭

## 技术实现

### 1. 智能分级算法

```javascript
// 多维度判断逻辑
determineNewsLevel(newsItem, result) {
  // 1. 基于事件重要性级别
  // 2. 基于关键词匹配（按优先级顺序）
  // 3. 基于公司影响力和情感分析
  // 4. 基于新闻内容长度和复杂性
  // 5. 默认级别 - Level 5 (信息性新闻)
}
```

### 2. 关键词分级体系

```javascript
// Level 1 - 全球性极大冲击
['全球经济危机', '股市崩盘', '国际战争', '总统辞职', '央行紧急干预']

// Level 2 - 重要但不如Level 1紧急  
['央行加息', '贸易战', '重大并购', '重大银行合并', '主要股指跌超10%']

// Level 3 - 行业或公司特定影响
['财报发布', '新能源汽车', '高管任命', '经济数据公布', '技术突破']

// Level 4 - 较小影响，背景性
['推出新产品', '市场分析报告', '公司内部变动', '行业研讨会']

// Level 5 - 纯信息性，无直接影响  
['例行更新', '统计数据', '会议纪要', '定期报告', '背景介绍']
```

### 3. 推送配置策略

| 级别 | 默认状态 | 推送类型 | 说明 |
|------|---------|----------|------|
| Level 1 | ✅ 启用 | 立即推送 | 无条件推送，市场重大影响 |
| Level 2 | ✅ 启用 | 重要推送 | 重点关注，较大影响 |
| Level 3 | ❌ 关闭 | 可选推送 | 可配置，特定关注 |
| Level 4 | ❌ 关闭 | 订阅推送 | 订阅用户，局部影响 |
| Level 5 | ❌ 关闭 | 背景推送 | 信息补充，无直接影响 |

```cypher
// 新增Level 5支持
CREATE INDEX news_level IF NOT EXISTS FOR (n:News) ON (n.news_level);
CREATE INDEX event_level IF NOT EXISTS FOR (e:Event) ON (e.event_level);
```

### 视图更新
```cypher
// 紧急新闻视图（Level 1）
CREATE OR REPLACE VIEW critical_news_events AS
MATCH (n:News {news_level: 'Level 1'})-[:REPORTED_IN]-(e:Event)
RETURN e, n ORDER BY n.timestamp DESC;
```

## 系统优势

### 1. 更精细的分类
- **5级分类**覆盖从全球性危机到信息性补充的完整光谱
- **避免信息过载**：Level 5作为默认级别，减少75%的无效推送
- **精准定位**：每个级别都有明确的影响范围和处理建议

### 2. 智能推送策略
- **差异化推送**：不同级别采用不同推送策略
- **噪音减少**：默认只推送Level 1和Level 2，减少信息干扰
- **可配置性**：用户可根据需求调整各级别推送设置

### 3. 增强的分析能力
```javascript
// 级别分布统计
{
  total: 1000,
  byLevel: {
    'Level 1': 5,    // 0.5% - 紧急新闻
    'Level 2': 25,   // 2.5% - 高优先级
    'Level 3': 150,  // 15% - 中等优先级  
    'Level 4': 320,  // 32% - 低优先级
    'Level 5': 500   // 50% - 信息性新闻
  }
}
```

### 4. 市场反应预测
- **Level 1**: 预期强烈市场反应，立即关注
- **Level 2**: 预期明显市场反应，重点监控
- **Level 3**: 预期温和市场反应，选择性关注
- **Level 4**: 预期轻微市场反应，背景了解
- **Level 5**: 预期无直接市场反应，信息存档
