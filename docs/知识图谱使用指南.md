# 新闻事件网络图 - 知识图谱功能使用指南

## 概述

本功能实现了一个智能新闻事件网络图系统，使用 Neo4j 图数据库存储新闻中的实体、事件及其关系。通过 AI 技术自动提取新闻内容中的关键信息，构建实体关系网络，为新闻总结和分析提供强大的数据支撑。

## 功能特性

- 🤖 **AI 实体提取**: 使用 AI 模型自动从新闻中提取实体、事件和关系
- 🔗 **实体归一化**: 智能识别和合并不同表达方式的同一实体（如"特朗普"和"唐纳德特朗普"）
- 📊 **图数据库存储**: 使用 Neo4j 存储复杂的实体关系网络
- 🔍 **强大查询功能**: 支持实体关系查询、时间线追踪、热门实体分析等
- 📈 **可视化支持**: 为后续新闻总结和草蛇灰线功能提供数据基础

## 系统架构

```
新闻数据 → AI实体提取 → 实体归一化 → Neo4j存储 → 查询分析
```

### 核心组件

1. **数据模型** (`src/models/GraphModels.js`)
   - 节点类型：实体、事件、新闻
   - 关系类型：参与、影响、CEO等
   - 实体类型：人物、组织、公司、地点等

2. **服务层**
   - `neo4jService.js`: Neo4j 数据库连接和基础操作
   - `entityExtractionService.js`: AI 实体提取服务
   - `knowledgeGraphService.js`: 知识图谱构建和查询核心服务

3. **管理脚本** (`src/scripts/graphTrigger.js`)
   - 初始化、数据处理、查询、健康检查等功能

## 安装和配置

### 1. 安装 Neo4j 数据库

**Docker 方式（推荐）:**
```bash
# 启动 Neo4j 容器
docker run \
    --name neo4j \
    -p 7474:7474 -p 7687:7687 \
    -d \
    -v $HOME/neo4j/data:/data \
    -v $HOME/neo4j/logs:/logs \
    -v $HOME/neo4j/import:/var/lib/neo4j/import \
    -v $HOME/neo4j/plugins:/plugins \
    --env NEO4J_AUTH=neo4j/your_password_here \
    neo4j:latest
```

**本地安装方式:**
1. 下载并安装 Neo4j Desktop 或 Community Edition
2. 创建数据库实例
3. 设置用户名和密码

### 2. 安装依赖

```bash
# 安装 Neo4j 驱动
npm install neo4j-driver
```

### 3. 环境变量配置

在项目根目录的 `.env` 文件中添加：

```env
# Neo4j 数据库配置
NEO4J_URI=bolt://localhost:7687
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=your_password_here
NEO4J_DATABASE=neo4j

# AI 服务配置（用于实体提取）
AI_BASE_URL=https://api.deepseek.com
AI_API_KEY=your_api_key_here
AI_MODEL=deepseek-reasoner
```

## 使用指南

### 1. 初始化系统

首次使用需要初始化知识图谱：

```bash
npm run graph:init
```

这将：
- 连接 Neo4j 数据库
- 创建必要的索引
- 显示数据库统计信息

### 2. 处理新闻数据

#### 处理最近的新闻
```bash
# 处理最近1小时的新闻
npm run graph:process

# 处理最近3小时的新闻
npm run graph:process latest 3
```

#### 处理指定时间范围的新闻
```bash
# 处理指定日期范围的新闻
npm run graph:process range 2024-01-01 2024-01-02
```

### 3. 查询知识图谱

#### 查询实体关系网络
```bash
# 查询"特斯拉"相关的实体关系
npm run graph:query entity "特斯拉"

# 查询"马斯克"的关系网络
npm run graph:query entity "马斯克"
```

#### 查询特定类型事件
```bash
# 查询价格变动事件
npm run graph:query events PriceChange

# 查询收购并购事件
npm run graph:query events Acquisition
```

#### 查询热门实体
```bash
# 显示最热门的实体（按提及次数排序）
npm run graph:query popular
```

#### 查询实体时间线
```bash
# 查询"特斯拉"最近7天的事件时间线
npm run graph:query timeline "特斯拉" 7

# 查询"马斯克"最近30天的事件时间线
npm run graph:query timeline "马斯克" 30
```

### 4. 搜索实体

```bash
# 搜索包含"特斯拉"的实体
npm run graph:search "特斯拉"

# 按类型搜索人物实体
npm run graph:search "马斯克" Person

# 搜索公司类型的实体
npm run graph:search "苹果" Company
```

### 5. 系统监控

#### 健康检查
```bash
npm run graph:health
```

#### 查看统计信息
```bash
npm run graph:stats
```

## 实体和事件类型

### 实体类型 (EntityTypes)

- **Person**: 人物（如：马斯克、特朗普）
- **Organization**: 组织/机构（如：国际货币基金组织）
- **Company**: 公司（如：特斯拉、苹果）
- **Location**: 地点（如：北京、华尔街）
- **Product**: 产品（如：iPhone、Model 3）
- **Currency**: 货币（如：美元、比特币）
- **Stock**: 股票（如：TSLA、AAPL）
- **Commodity**: 商品（如：黄金、原油）
- **Concept**: 概念（如：人工智能、新能源）

### 事件类型 (EventTypes)

- **PriceChange**: 价格变动
- **Acquisition**: 收购/并购
- **Partnership**: 合作
- **Conflict**: 冲突/争议
- **Announcement**: 公告/发布
- **PolicyChange**: 政策变化
- **FinancialResult**: 财务业绩
- **MarketMove**: 市场动向
- **LeadershipChange**: 人事变动
- **ProductLaunch**: 产品发布
- **EconomicIndicator**: 经济指标

### 关系类型 (RelationshipTypes)

#### 实体与事件的关系
- **PARTICIPATED_IN**: 参与事件
- **AFFECTED_BY**: 受事件影响
- **CAUSED**: 造成事件

#### 实体与实体的关系
- **CEO_OF**: CEO关系
- **OWNS**: 拥有关系
- **SUBSIDIARY_OF**: 子公司关系
- **PARTNER_OF**: 合作关系
- **COMPETITOR_OF**: 竞争关系
- **LOCATED_IN**: 位于
- **WORKS_FOR**: 工作于
- **LEADS**: 领导
- **RELATED_TO**: 相关

## 数据流程示例

### 新闻处理流程

1. **输入新闻**:
   ```
   标题: "特斯拉股价上涨5%，马斯克发推回应"
   内容: "特斯拉公司股价今日上涨5%，CEO马斯克在推特上表示对公司前景看好..."
   ```

2. **AI 实体提取**:
   ```json
   {
     "entities": [
       {"name": "特斯拉", "type": "Company", "aliases": ["Tesla"]},
       {"name": "马斯克", "type": "Person", "aliases": ["埃隆·马斯克"]}
     ],
     "events": [
       {"type": "PriceChange", "description": "股价上涨5%", "sentiment": "positive"}
     ],
     "relationships": [
       {"type": "CEO_OF", "from": "马斯克", "to": "特斯拉"}
     ]
   }
   ```

3. **图数据库存储**:
   - 创建/更新实体节点：特斯拉(Company)、马斯克(Person)
   - 创建事件节点：股价上涨事件
   - 创建关系：马斯克 CEO_OF 特斯拉
   - 链接实体与新闻、事件与新闻

### 查询示例

查询"特斯拉"相关信息时，系统会返回：
- 特斯拉实体的详细信息
- 与特斯拉相关的所有事件
- 与特斯拉有关系的其他实体（如马斯克、供应商等）
- 相关新闻和时间线

## 高级功能

### 实体归一化

系统会自动识别和合并相同实体的不同表达：
- "特朗普" 和 "唐纳德·特朗普" → 合并为同一实体
- "苹果公司" 和 "Apple Inc." → 合并为同一实体
- "TSLA" 和 "特斯拉股票" → 识别为相关实体

### 关系推理

系统支持多层关系查询，可以发现间接关系：
- 马斯克 → CEO_OF → 特斯拉 → COMPETITOR_OF → 苹果
- 通过关系链发现马斯克与苹果的竞争关系

### 时间维度分析

支持基于时间的事件分析：
- 实体的事件时间线
- 特定时期的热门事件
- 事件发展趋势分析

## 故障排查

### 常见问题

1. **Neo4j 连接失败**
   - 检查 Neo4j 服务是否启动
   - 验证连接配置（URI、用户名、密码）
   - 确认防火墙设置

2. **AI 实体提取失败**
   - 检查 AI API 密钥配置
   - 验证网络连接
   - 查看日志获取详细错误信息

3. **实体提取质量不佳**
   - 调整 AI 提示词模板
   - 增加实体类型映射规则
   - 优化实体归一化逻辑

### 性能优化

1. **批量处理**: 使用批量模式处理大量新闻
2. **索引优化**: 确保关键字段有索引
3. **缓存策略**: 对频繁查询的结果进行缓存
4. **并发控制**: 控制并发处理数量避免过载
