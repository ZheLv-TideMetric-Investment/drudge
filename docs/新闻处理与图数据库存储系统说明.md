# 新闻处理与图数据库存储系统

基于新闻六要素（5W1H）的智能新闻分析系统，支持实时突发新闻识别、按小时总结和事件关联追踪。

## 🎯 系统特性

- **📰 智能新闻处理**: 基于5W1H原则提取新闻六要素
- **🚨 Break News识别**: 实时识别和推送突发新闻  
- **📊 按小时总结**: AI生成的智能新闻总结
- **🐍 草蛇灰线追踪**: 基于图数据库的事件关联分析
- **🎯 知识图谱构建**: 自动构建新闻事件关系网络

### 数据模型设计

基于新闻六要素（5W1H）的图数据库节点设计：

```
Event (What+How)    ←→    Company (Who-企业)
    │                         │
    │                         │
    ▼                         ▼
Person (Who-个人)   ←→    Organization (Who-机构)
    │                         │
    │                         │
    ▼                         ▼
Location (Where)    ←→    Time (When)
```

#### 节点类型

- **Event**: 事件节点 (What + How)
  - `event_name`: 事件名称
  - `event_description`: 事件描述
  - `event_type`: 事件类型
  - `significance`: 重要性级别 (1-4)
  - `sentiment`: 情感倾向
  - `magnitude`: 影响程度

- **Company**: 公司节点 (Who - 企业)
  - `company_name`: 公司名称
  - `ticker`: 股票代码
  - `industry`: 行业分类

- **Person**: 人物节点 (Who - 个人)
  - `person_name`: 人物姓名
  - `role`: 职位角色
  - `company`: 所在公司

- **Organization**: 机构节点 (Who - 机构)
  - `organization_name`: 机构名称
  - `type`: 机构类型
  - `country`: 所属国家

- **Location**: 地点节点 (Where)
  - `location_name`: 地点名称
  - `country`: 所属国家
  - `region`: 地区

- **Time**: 时间节点 (When)
  - `timestamp`: 时间戳
  - `date`: 日期
  - `hour`: 小时
  - `time_of_day`: 时间段

#### 关系类型

- **OCCURRED_IN**: 事件发生在某公司
- **INVOLVES**: 事件涉及某人物
- **OCCURRED_AT**: 事件发生在某地点
- **HAPPENED_AT**: 事件发生在特定时间
- **BELONGS_TO**: 地点属于某国家
- **CEO_OF**: 人物是某公司的CEO
- **REPORTED_IN**: 事件在新闻中报道

## 🚀 功能详解

### 1. Break News功能

**自动识别突发新闻并实时推送**

#### 判断标准
- 事件重要性级别达到4级（极高）
- 包含突发关键词："突发"、"紧急"、"崩盘"等
- 涉及重要公司的重大负面事件
- 短时间内多条相关报道

#### 推送内容
```
🚨 BREAK NEWS 🚨
⏰ 时间：2025-01-19 14:30:00

📰 新闻标题
标题内容

🔥 重大事件
1. 事件名称
   事件描述
   重要性: 🔴 极高
   情感倾向: 📉 负面

🏢 涉及公司：公司名称
👤 涉及人物：人物名称(职位)

⚠️ 风险提醒
1. 可能对相关公司股价产生重大负面影响
2. 建议密切关注事件发展动态
```

#### 运行机制
- **实时检查**: 每条新闻处理时自动检查
- **主动扫描**: 每5分钟扫描图数据库中的高重要性事件
- **去重机制**: 1小时内相同事件不重复推送

### 2. 按小时总结功能

**每小时智能总结新闻动态**

#### 运行时间
- 每小时的第5分钟执行（如：14:05）
- 总结上一小时的所有新闻

#### 总结内容
```
📊 按小时新闻总结 📊
⏰ 时间段：2025-01-19 13:00 - 14:00

📈 基本统计
📰 总新闻数：25
🚨 突发新闻：2

🤖 智能总结
本小时财经市场较为活跃，主要聚焦于...
[AI生成的专业总结]

🔥 重要事件 (按重要性排序)
1. 🔴 事件1
2. 🟠 事件2
3. 🟡 事件3

🏢 活跃公司 (按提及次数排序)
1. 苹果公司 (5次)
2. 微软 (3次)

📊 市场分析
⚠️ 本小时出现2条突发新闻，市场可能出现波动
```

#### AI总结生成
- 使用专业提示词模板
- 分析事件类型和市场影响
- 提供风险提醒和投资建议
- 回退到模板总结（AI失败时）

### 3. 草蛇灰线功能

**基于图数据库的事件关联追踪**

#### 核心查询功能

**公司事件追踪**
```cypher
MATCH (c:Company {company_name: "Apple Inc."})<-[:OCCURRED_IN]-(e:Event)
RETURN e ORDER BY e.event_date DESC LIMIT 50
```

**多公司关联分析**
```cypher
MATCH (c1:Company)<-[:OCCURRED_IN]-(e:Event)-[:OCCURRED_IN]->(c2:Company)
WHERE c1.company_name IN ["Apple Inc.", "Microsoft"] 
  AND c2.company_name IN ["Apple Inc.", "Microsoft"]
  AND c1 <> c2
RETURN DISTINCT e, collect(DISTINCT c1.company_name) + collect(DISTINCT c2.company_name) as companies
```

**某日事件分析**
```cypher
MATCH (t:Time {date: "2025-01-19"})<-[:HAPPENED_AT]-(e:Event)
OPTIONAL MATCH (e)-[:OCCURRED_IN]->(c:Company)
RETURN e, collect(DISTINCT c.company_name) as companies
ORDER BY t.timestamp
```

#### 分析维度

**事件模式分析**
- 事件类型分布统计
- 情感倾向分析（正面/负面/中性）
- 重要性趋势分析
- 时间聚集模式识别

**市场影响分析**
- 市场影响评分计算（0-100）
- 行业影响分析
- 风险等级评估（低/中/高/极高）
- AI生成的深度洞察

#### 定时报告
- **每小时HH:10**: 重点公司事件追踪
- **每天22:00**: 当日重要事件总结
- **手动触发**: 支持API调用

### 4. 知识图谱构建

**自动构建新闻事件关系网络**

#### 处理流程
1. **新闻六要素提取**: 使用AI从新闻中提取5W1H信息
2. **节点创建**: 在图数据库中创建各类实体节点
3. **关系建立**: 根据新闻内容和推理建立实体间关系
4. **图谱更新**: 合并相似实体，更新关系强度

#### 查询接口
```javascript
// 搜索实体
await knowledgeGraphService.searchEntities("苹果", "Company", 10);

// 获取Break News事件
await knowledgeGraphService.getBreakNewsEvents(20);

// 获取图谱统计
await knowledgeGraphService.getGraphStats();
```
