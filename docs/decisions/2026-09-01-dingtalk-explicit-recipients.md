# 主动推送使用显式单收件人

决定日期：2026-09-01。状态：已实施；收件人原则继续有效，展示方式由[图片摘要与 H5 决定](2026-09-03-image-briefing-h5.md)接续。当前配置和验收只维护在[消息手册](../dingtalk-briefing.md)。

## 原因

旧群 Webhook 隐含接收范围，无法明确控制谁会收到。用户选择复用企业机器人“牛长婷”，并要求收件人可配置、绝不默认向所有人发送。

## 有效决定

- Web 主动通知只走企业机器人与一个显式用户的单聊，用户不能写死为仓库所有者。
- 代码和配置模板默认关闭；必须配置合法单收件人才允许投递。生产是否开启以运行配置和发布验收为准。
- 不使用群 ID、`atAll`、组织可见范围或广播 fallback；未来多人能力必须显式白名单并记录逐人结果。
- 发送失败不能推进已发送状态；钉钉接口接受与用户实际呈现分别验收。
- 两个 worker 的异常告警 Webhook 不受此决定影响。

## 取代与回退

Web 旧群 Webhook 路径已由单聊实现取代。此前探索的互动卡片与禁止转发描述不再有效；普通 Markdown 图片与 H5 链接可被人工转发。

停用或回退遵循消息和部署手册，不能恢复隐式群发。本决定解释架构选择，本身不新增真实发送或生产操作授权。
