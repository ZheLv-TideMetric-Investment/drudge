# 新闻系统分层处理功能

## 概述

新闻系统现已支持三层分层处理架构，在保持原有功能的基础上，新增了更精细化的数据处理流程。

## 架构层次

### 1. Original-Hour News (OHN)
**执行时间**: 每小时 HH:02  
**功能**: 对过去1小时的原始新闻进行去重和压缩处理  
**输出**: `data/ohn/YYYYMMDD/HH.json`

#### 处理流程
- 从原始新闻数据中读取过去1小时的内容
- **AI智能处理**：模型自动进行信息提炼和重复新闻去重
- **智能压缩**：减少字符数量但不减少信息量，保持数字准确性
- **自动分类**：按5大类别分类存储
  - 宏观政策/系统风险
  - 跨市场价格冲击  
  - 行业/主题驱动
  - 大型主体事件
  - 一般公司/区域性新闻

### 2. Hour News Summary (HNS)
**执行时间**: 每小时 HH:05  
**功能**: 基于OHN数据生成小时摘要  
**输出**: `data/hns/YYYYMMDD/HH.json`  
**推送**: 工作时间(11-22点)自动推送钉钉

#### 处理流程
- 读取上一小时的OHN数据
- 使用AI服务生成新闻摘要
- 保存摘要结果
- 在工作时间推送到钉钉群

### 3. Overnight Summary
**执行时间**: 每天 10:05  
**功能**: 汇总前一天22:00-当日10:00的夜间新闻  
**输出**: `data/overnight/YYYYMMDD.json`  
**推送**: 自动推送钉钉

#### 处理流程
- 读取夜间时段(22:00-10:00)的所有OHN数据
- 生成夜间时段综合摘要
- 推送夜间汇总到钉钉群

## 目录结构

```
data/
├── news/           # 原始新闻数据 (现有)
├── ohn/            # Original-Hour News (AI分类存储)
│   └── YYYYMMDD/
│       ├── 00.json                   # 00点的分类新闻数据
│       ├── 01.json                   # 01点的分类新闻数据
│       └── ...
├── hns/            # Hour News Summary
│   └── YYYYMMDD/
│       ├── 00.json
│       ├── 01.json
│       └── ...
├── overnight/      # 夜间汇总
│   ├── 20240101.json
│   └── ...
└── hunts/          # 草蛇灰线捕猎对象
    ├── hunt_*.json
    └── ...
```

## 手动触发命令

### 基础命令
```bash
# 原有功能
npm run trigger:fetch       # 获取最新新闻
npm run trigger:last-hour   # 总结上一小时新闻
npm run trigger:custom      # 自定义时间总结

# 分层处理功能
npm run trigger:ohn         # 运行OHN处理
npm run trigger:hns         # 运行HNS生成
npm run trigger:overnight   # 运行夜间汇总

# 草蛇灰线系统
npm run snake:hunt          # 手动触发事件捕猎
npm run snake:progress      # 手动触发进展检查
npm run snake:status        # 查看系统状态
npm run snake:report        # 生成系统报告
npm run snake:health        # 健康检查
```

### 高级命令
```bash
# 指定时间测试
node src/scripts/manualTrigger.js test-ohn-custom 2024-01-01-15
```

## API兼容性

所有新功能均为增量添加，**完全兼容现有接口和功能**：

- 原有的新闻获取流程保持不变
- 原有的定时摘要任务继续运行
- 原有的钉钉推送机制保持不变
- 原有的数据存储格式兼容

## 调度时间表

| 时间 | 任务 | 输入 | 输出 | 钉钉推送 |
|------|------|------|------|----------|
| 每分钟 | 新闻获取 | API | /raw | - |
| 每分钟 | 草蛇灰线进展检查 | - | - | 有进展时 |
| 每5分钟 | 草蛇灰线事件捕猎 | /raw | /hunts | 发现特级事件时 |
| 每小时 | 草蛇灰线终止检查 | - | - | 终止时 |
| HH:02 | OHN处理 | /raw | /ohn | - |
| HH:05 | HNS生成 | /ohn | /hns | 11-22点 |
| HH:01 (11-22点) | 原有摘要 | /raw | - | ✓ (兼容) |
| 10:01 | 原有夜间摘要 | /raw | - | ✓ (兼容) |
| 10:05 | 新夜间汇总 | /ohn | /overnight | ✓ |
