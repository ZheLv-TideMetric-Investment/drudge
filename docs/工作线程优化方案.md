# 工作线程优化方案

## 问题背景

在实际运行中发现，当系统开始处理新闻后，每分钟的定时任务会被阻塞无法执行。这是因为：

1. **事件循环阻塞**：AI调用和数据库操作是CPU和I/O密集型任务
2. **长时间处理**：单批新闻处理可能需要2-3分钟甚至更长
3. **定时任务失效**：Node.js的单线程特性导致定时任务无法按时执行

## 解决方案：Worker Threads

采用Worker Threads（工作线程）方案，将重CPU操作移到独立线程中执行，保持主线程事件循环畅通。

### 架构设计

```
主线程（Main Thread）
├── 定时任务调度
├── 系统监控
├── Webhook通知
└── 工作线程管理

工作线程池（Worker Pool）
├── Worker 1: 新闻处理
├── Worker 2: 新闻处理
└── Worker N: 新闻处理
```

## 核心组件

### 1. 新闻处理工作线程 (`newsProcessorWorker.js`)

负责在独立线程中执行新闻处理逻辑：

```javascript
// 支持的操作类型
- PROCESS_SINGLE: 处理单条新闻
- PROCESS_BATCH: 批量处理新闻
- PING: 健康检查
```

**特性：**
- 独立的服务初始化
- 完整的错误处理
- 消息通信机制
- 自动初始化检查

### 2. 工作线程管理器 (`workerManager.js`)

管理工作线程池的生命周期：

```javascript
// 核心功能
- 线程池初始化和管理
- 任务分发和调度
- 健康监控和故障恢复
- 优雅关闭
```

**特性：**
- 动态线程池大小
- 任务队列机制
- 超时和重试
- 自动故障恢复

## 工作流程

### 1. 系统启动
```
1. 主线程启动
2. 初始化工作线程池
3. 每个工作线程独立初始化服务
4. 建立消息通信通道
5. 开始定时任务调度
```

### 2. 新闻处理
```
1. 定时任务触发（主线程）
2. 获取新闻列表（主线程）
3. 发送处理任务到工作线程
4. 工作线程执行AI和数据库操作
5. 返回处理结果到主线程
6. 主线程更新统计和发送通知
```

### 3. 任务调度
```
- 可用线程：立即执行
- 无可用线程：加入任务队列
- 线程释放：自动处理队列任务
- 任务超时：自动重试或失败
```

## 配置说明

### 环境变量配置

```bash
# 工作线程配置
WORKERS_ENABLED=true              # 是否启用工作线程（默认true）
MAX_WORKERS=2                     # 最大工作线程数（默认2）
WORKER_TIMEOUT=300000             # 任务超时时间（默认5分钟）
WORKER_HEALTH_CHECK_INTERVAL=60000 # 健康检查间隔（默认1分钟）
```

### 代码配置

```javascript
// src/config/config.js
workers: {
  enabled: process.env.WORKERS_ENABLED !== 'false',
  maxWorkers: parseInt(process.env.MAX_WORKERS || '2', 10),
  timeout: parseInt(process.env.WORKER_TIMEOUT || '300000', 10),
  healthCheckInterval: parseInt(process.env.WORKER_HEALTH_CHECK_INTERVAL || '60000', 10),
}
```

## 性能优势

### 1. 事件循环保持畅通
- **主线程专注**：只处理定时任务、监控、通知
- **无阻塞**：AI和数据库操作在工作线程中执行
- **实时响应**：定时任务能够按时执行

### 2. 并发处理能力
- **多线程**：同时处理多个新闻批次
- **资源利用**：充分利用多核CPU
- **吞吐量提升**：理论上可提升2-4倍

### 3. 故障隔离
- **线程隔离**：单个线程崩溃不影响其他线程
- **自动恢复**：异常线程自动重启
- **降级处理**：工作线程失败时自动回退到主线程

## 兼容性和回退

### 1. 主线程模式

如果禁用工作线程，系统会自动回退到主线程模式：

```javascript
// 设置环境变量
WORKERS_ENABLED=false

// 或修改配置
workers: { enabled: false }
```

### 2. 自动回退机制

工作线程出现问题时，系统会自动回退：

```javascript
try {
  result = await workerManager.processBatchNews(newsItems);
} catch (error) {
  logger.error('工作线程批量处理失败，回退到主线程:', error);
  // 自动使用主线程处理
  result = await this.processSingleNewsInMainThread(newsItems);
}
```
