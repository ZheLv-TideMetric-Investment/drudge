# 新闻处理性能优化说明

## 优化概述

本次优化主要解决了新闻处理系统中的性能瓶颈和任务堆积问题，实现了以下三个核心需求：

1. **任务堆积警告机制**：监控处理状态，及时发现性能问题
2. **手动触发功能**：支持手动处理所有本地存储的新闻
3. **幂等性保证**：确保同一条新闻只处理一次

## 性能问题分析

### 原问题
- `processNewsItems` 执行时间可能超过1分钟，影响每分钟的定时获取
- 缺乏任务状态监控，无法及时发现堆积问题
- 没有幂等性检查，可能重复处理相同新闻
- 缺乏手动干预机制

### 影响
- 定时任务堆积，系统负载增加
- 资源浪费，重复处理相同内容
- 无法及时处理历史数据

## 优化方案

### 1. 任务状态监控与警告

#### 任务状态跟踪
```javascript
this.currentTaskInfo = {
  isProcessing: false,    // 是否正在处理
  startTime: null,        // 开始时间
  newsCount: 0,          // 处理新闻数量
  taskType: null         // 任务类型
};
this.pendingNewsQueue = [];  // 待处理队列
```

#### 警告机制
- **任务超时警告**：任务运行超过2分钟时发送警告
- **队列堆积警告**：待处理队列超过50条时发送警告
- **警告限流**：每10分钟最多发送一次警告，避免垃圾信息

#### 警告消息示例
```
⚠️ **任务堆积警告**

当前任务已运行：180秒
任务类型：scheduled
处理新闻数：25条
待处理队列：67条
建议检查系统性能或手动干预
```

### 2. 幂等性保证

#### 数据库层面检查
```javascript
async isNewsProcessed(newsId) {
  const cypher = `
    MATCH (n:News {id: $newsId, processed: true})
    RETURN n
    LIMIT 1
  `;
  
  const result = await neo4jService.executeQuery(cypher, { newsId });
  return result.records.length > 0;
}
```

#### 批量幂等性检查
```javascript
async getUnprocessedNewsIds(newsIds) {
  const cypher = `
    WITH $newsIds as ids
    UNWIND ids as newsId
    OPTIONAL MATCH (n:News {id: newsId, processed: true})
    WITH newsId, n
    WHERE n IS NULL
    RETURN newsId
  `;
  
  const result = await neo4jService.executeQuery(cypher, { newsIds });
  return result.records.map(record => record.get('newsId'));
}
```

#### 处理流程优化
1. **预过滤**：处理前先过滤掉已处理的新闻
2. **状态标记**：创建新闻节点时设置`processed: true`
3. **跳过记录**：已处理的新闻直接跳过，避免重复计算

### 3. 智能任务调度

#### 任务类型分类
- `scheduled`：定时任务
- `manual`：手动触发
- `queued`：队列处理

#### 调度策略
```javascript
// 检查是否有任务正在运行
if (this.currentTaskInfo.isProcessing && taskType === 'scheduled') {
  // 将新闻添加到待处理队列
  this.pendingNewsQueue.push(...newsItems);
  logger.warn(`当前有任务正在运行，将${newsItems.length}条新闻添加到待处理队列`);
  await this.checkTaskBacklogAndWarn();
  return;
}
```

#### 队列处理
- 任务完成后自动处理待处理队列
- 支持队列优先级（手动任务优先于定时任务）
- 避免无限递归（手动任务不触发队列处理）

#### 手动处理逻辑
```javascript
async manualProcessAllNews(options = {}) {
  // 1. 获取所有本地存储的新闻
  const allStoredNews = await storageService.getAll(options.limit);
  
  // 2. 过滤未处理的新闻（幂等性保证）
  const unprocessedNews = await filterUnprocessedNews(allStoredNews);
  
  // 3. 批量处理或单条处理
  await this.processNewsItems(unprocessedNews, 'manual');
  
  // 4. 发送完成通知
  await sendCompletionNotification();
}
```
