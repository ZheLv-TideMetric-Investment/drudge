## 核心特性

### 智能通知系统
- **根据调用来源决定通知行为**：
  - `CallSource.SCHEDULER`: 定时任务调用 → 发送通知
  - `CallSource.API`: 手动 API 调用 → 不发送通知
  - `CallSource.CLI`: CLI 调用 → 不发送通知

### 任务调度详情
1. **高级别新闻扫描**
   - 频率：每5分钟
   - 目标：Level 1 和 Level 2 新闻
   - 行为：发现新新闻时发送通知

2. **小时总结**
   - 频率：工作时间(11:00-22:00)每小时整点
   - 功能：AI 生成小时新闻总结
   - 行为：有高级别新闻时发送通知

3. **每日总结**
   - 频率：每天10:00
   - 范围：前一天22:00到当天10:00
   - 行为：始终发送每日总结通知

### 架构优势
- **Next.js 13+ App Router**：使用最新架构
- **函数式编程**：避免类式编程，符合您的要求
- **TypeScript**：完整类型安全
- **模块化设计**：清晰的服务分层
- **优雅关闭**：支持进程信号处理

## 环境配置

创建 `.env.local` 文件：

```bash
# Neo4j 数据库配置
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=password
NEO4J_DATABASE=neo4j

# 通知配置
ENABLE_WEBHOOK_NOTIFICATION=true
WEBHOOK_URL=https://your-webhook-url.com/webhook

# 定时任务配置
CRON_HIGH_LEVEL_SCAN=0 */5 * * * *
CRON_HOURLY_SUMMARY=0 0 11-22 * * *
CRON_DAILY_SUMMARY=0 0 10 * * *

# 日志配置
LOG_LEVEL=info
LOG_FILE=logs/app.log
```
