# 简报 PNG 中文字体

Noto Sans SC Regular / Bold，用于服务器渲染简报。字体随 standalone 复制，不依赖 Linux 系统字体，也不在客户端请求远程字体。事件字号、颜色和位置仍由 `briefing-image.ts` 决定。

来源：[Noto CJK Sans 2.004](https://github.com/notofonts/noto-cjk/tree/523d033d6cb47f4a80c58a35753646f5c3608a78/Sans/SubsetOTF/SC)，原文件未经修改。字体许可见同目录 [LICENSE](LICENSE)。
